# Emisie superradiantă de lumină cu moment cinetic orbital &mdash; Prezentare

## Rezumat

Acest repo conține fișierele sursă pentru prezentarea „_Emisie superradiantă de lumină cu moment cinetic orbital prin împrăștierea unui fascicul Laguerre-Gauss de un mănunchi de electroni_”, pe care am prezentat-o la Conferința Anuală de Comunicare a Rezultatelor Cercetării la UB, ediția 2026.

## Cerințe software

Pentru a compila prezentarea în format PDF, sunt necesare cel puțin următoarele unelte:

- [`lualatex`](https://www.luatex.org/)
- [`latexmk`](https://www.cantab.net/users/johncollins/latexmk/)
- [`tex-fmt`](https://github.com/WGUNDERWOOD/tex-fmt) (_opțional_): pentru formatarea automată a fișierelor sursă TeX

Acestea sunt incluse de obicei în distribuția [TeX Live](https://tug.org/texlive/).
